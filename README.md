#### 使用说明

1.  访问地址
    * https://flyerhome.github.io/flyer-draw/

2. 截图样例
    ![img.png](img.png)

3. 操作绘图
   * 画圆和画矩形直接鼠标拖拽即可
   * 画矩形支持 shift长按 画正方形
   * 画多边形鼠标点一次定位一个顶点，最后可以使用 Enter 结束画图 鼠标最后存在的位置为最后一个顶点
   * 画多边形最后可以使用 esc 也可以 结束画图，鼠标最后存在的位置不会作为最后一个顶点

4. 开发思路
   * mousedown事件
     * 确定绘制的起点 x y
     * 确定选中目标 current.selected
   * mousemove事件
     * 绘制过程中
       * 移动鼠标确定圆的半径 r
       * 移动鼠标确定矩形的宽高 width height
       * 移动鼠标寻找多边形的下一个点位
     * 选中目标
       * 移动鼠标，修改圆的起点位置 x y
       * 移动鼠标，修改矩形的起点位置 x y
       * 移动鼠标， 修改多边形的各个顶点 points
       * 移动鼠标，修改文本的位置 x y
   * mouseup事件
     * 结束绘制
     * 结束移动
